Factory Reference

  • Pallets
    • Each labeled pallet represents one original value. Count the pallets, not the physical gear pieces.
    • Equal starting values still count separately. An empty pallet also counts.
  • Gear Quantity
    • One whole gear is one unit; two half-gears together are one unit.
    • Moving, splitting, or merging preserves the total and the original records.
  • Mean
    • The equal share: total gears ÷ number of pallets.
    • It can be a value that never appeared in the original data.
  • Median
    • Found by ordering the original values and locating the middle.
    • Median Depot practices that different action.
