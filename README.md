# Mean Machine

A proposed educational factory game for exploring the arithmetic mean through equal sharing.

**Status: Brainstorming.** No playable application or implementation roadmap is included yet.

Start with the [Non-Binding Concept Notes](docs/CONCEPT-NOTES.md), recorded September 27, 2026. They preserve the discussion for a later roadmap conversation; they are not an approved specification or feature commitment.

The intended planning sequence is concept notes, a focused roadmap conversation, concrete issues, and implementation PRs.

Companion project: [Skimmer Data Center](https://github.com/AbbyUsesAIThatCodes/SkimmerDataCenter), focused on spreadsheet skills and interpreting skimmer flight data. The projects are separate so each can be developed and tested independently.
